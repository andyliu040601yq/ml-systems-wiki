# ML Systems, Agents & RSI Wiki

An interconnected research wiki covering machine learning systems, agent systems,
and recursive self-improvement (RSI). It integrates original papers with reusable
technical concepts and comparisons across these areas.

## Topics

This wiki focuses on topics including:

- GPU architecture and programming
- CUDA and Triton
- ML/LLM inference systems
- Model serving
- KV cache management
- Efficient attention
- Sparse attention
- Distributed training and inference
- AI infrastructure
- Agent architectures, harnesses, tools, and long-horizon execution
- Agentic optimization and recursive improvement of workflows, harnesses, and systems
- Recursive self-improvement (RSI), its mechanisms, evaluation, and safety boundaries
- Related algorithms and systems research

## Structure

- `raw/` contains original source materials.
- `wiki/papers/` contains paper notes and analyses.
- `wiki/concepts/` contains reusable technical concepts.
- `wiki/comparisons/` contains comparisons and synthesized analyses.
- Pages can connect topics across ML systems, agents, and RSI; they are not separate silos.
- `index.md` is the main knowledge index.
- `log.md` records the evolution of the knowledge base.

## Workflow

Original materials are preserved under `raw/` as sources of truth.

For each source, the wiki records its system design and evidence, then updates
relevant paper, concept, and comparison pages with traceable cross-links. New
material should strengthen the shared knowledge base rather than remain an isolated
summary.
