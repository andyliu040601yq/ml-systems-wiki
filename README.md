# ML Systems Wiki

My personal knowledge base for learning and researching machine learning systems.

## Topics

This wiki focuses on topics including:

- GPU architecture and programming
- CUDA and Triton
- ML/LLM inference systems
- Model serving
- KV cache management
- Efficient attention
- Sparse attention
- Distributed training and inference
- AI infrastructure
- Agentic systems for ML infrastructure
- Related algorithms and systems research

## Structure

- `raw/` contains original source materials.
- `wiki/papers/` contains paper notes and analyses.
- `wiki/concepts/` contains reusable technical concepts.
- `wiki/comparisons/` contains comparisons and synthesized analyses.
- `index.md` is the main knowledge index.
- `log.md` records the evolution of the knowledge base.

## Workflow

Original materials are added to `raw/`.

Codex reads these sources and incrementally maintains the structured wiki.
As new sources are added, existing pages should be updated and cross-linked rather
than treating every source independently.
